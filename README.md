# CodeAtlas

The Free Computer Science Learning, Practice, Project & Career Platform

## Tech Stack

- Next.js 16 + TypeScript + Tailwind CSS v4
- Supabase (Postgres, Auth)
- Framer Motion, GSAP
- AI Integration (Gemini) with quota system

## Getting Started

`ash
npm install
npm run dev
`

## Development

`ash
npm run dev      # Start development server
npm run build    # Build for production
npm run start    # Start production server
npm run lint     # Run ESLint
`

## Design

Dark premium theme with warm beige, cream, and green accents.
